# Lenvry 🚀

A comprehensive personal tracking mobile application built with **React Native** and **Expo Router**. Lenvry helps you track your fitness, habits, nutrition, and financial transactions all in one place with offline-first local storage.

## ✨ Features

- **Fitness Tracker:** Track workouts, burn goals, and physical activities.
- **Habit Tracker:** Build daily habits and track streaks with notification reminders.
- **Nutrition Tracker:** Log meals, calories, macros, and scan food images.
- **Finance Manager:** Manage income, expenses, and category budgets.
- **Backup & Restore:** Export and import your data locally anytime.

## 🛠️ Tech Stack

- **Framework:** [Expo](https://expo.dev/) / [React Native](https://reactnative.dev/)
- **Routing:** [Expo Router](https://docs.expo.dev/router/introduction/)
- **Storage:** `@react-native-async-storage/async-storage`
- **Language:** TypeScript

## 🚀 Getting Started

### Prerequisites

Make sure you have Node.js and npm/bun installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/diityanug/Lenvry.git
   cd Lenvry
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npx expo start
   ```

Scan the QR code with **Expo Go** (Android/iOS) or run on an emulator/simulator.
